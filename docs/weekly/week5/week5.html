MH1 — MULTI-VPC CONNECTIVITY
Architecture decision

Path C — Justified Single-VPC

Technical Justification: Single-VPC

  • Boundary Assessment: Kiến trúc hiện tại không yêu cầu multi-tenant isolation hay strict compliance (PCI-DSS), Single-VPC là "sweet spot" giữa bảo mật và độ phức tạp.
  • Micro-segmentation: Phân lớp Subnet (Public/Private/Intra/DB) kết hợp Security Groups đã đáp ứng đủ nguyên tắc "Defense in Depth" nội bộ.
  • Cost-Performance Trade-off: Tránh Data Transfer Cost và network hops (latency) của Transit Gateway giữa các module đang giao tiếp cường độ cao.

Vẫn đảm bảo isolation bằng subnet tầng

Public: ALB / NATPrivate: ECS FargateIntra: Firewall EndpointDatabase: Redis / DB

Trigger tách VPC tương lai: Payment Gateway cần PCI-DSS Level 1.
