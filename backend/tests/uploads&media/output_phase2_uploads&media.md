## Test Execution Notes

### Prerequisites for Running Tests

1. **Backend Unit Tests**:

   - Jest configured with ES modules
   - Mocks for: multer, cloudinary, fs, logger
   - Mock environment variables

2. **Integration Tests**:

   - Test database (MongoDB Memory Server)
   - Cloudinary test account or mocked service
   - Test user credentials
   - Supertest for HTTP testing

3. **Frontend Tests**:
   - React Testing Library
   - Mock axios/MSW
   - Mock File API
   - JSDOM environment

### Mocking Strategy

- **Cloudinary**: Use `jest.mock('cloudinary')` to avoid real uploads
- **File System**: Mock `fs` module for directory tests
- **Network**: Use `nock` or MSW for HTTP mocking
- **Logger**: Spy on logger methods to verify logging

### Test Data Requirements

- Sample images: 1MB, 5MB, 10MB, 15MB JPG files
- Invalid files: .exe, .pdf, .txt for negative tests
- Corrupted image file for error testing
- Large dimension images: 2000x2000, 8000x8000

### Coverage Goals

- **Unit Tests**: >90% coverage on upload.middleware.js, cloudinary.js
- **Integration Tests**: All endpoints tested with happy/error paths
- **Edge Cases**: All critical security and performance scenarios
